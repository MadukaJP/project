# Aptech AI & ML Projects

This repository contains my Artificial Intelligence and Machine Learning projects while studying at **Aptech Computer Education**.

## Current Project

### 1) Churn Risk Profiling (GMM)
- **Folder:** `churn_risk_profiling_gmm`
- **Goal:** Profile customer churn risk into segments such as Power User, Standard User, and At-Risk user.
- **Model:** Gaussian Mixture Model (GMM)
- **Dataset:** Customer subscription churn and usage patterns

## Stack Used

- **Python** for backend and ML integration
- **FastAPI** for serving prediction endpoints
- **scikit-learn**, **NumPy**, and **joblib** for model training/inference artifacts
- **HTML + Tailwind CSS + Chart.js** for the frontend dashboard
